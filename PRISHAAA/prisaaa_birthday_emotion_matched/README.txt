PRISAAA BIRTHDAY WEBSITE

This folder contains the website and the music clip used by its player.

FILES
- index.html: the complete birthday website. The pictures/illustrations are embedded in this HTML file, so separate image files are not needed.
- assets/music/combined_singing.mp3: the music clip used by the website (the 28–58 second section).

TO TEST
1. Extract the whole ZIP file.
2. Keep the folder structure unchanged.
3. Open index.html in a browser. Press the website's play button to start the music.

TO PUT IT ONLINE
Upload index.html and the assets folder to your GitHub repository, preserving the folder structure, then deploy the repository with Vercel.
